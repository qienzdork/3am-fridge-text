# The 3AM Fridge Text

One line a smart fridge texts its owner at 3am — entered in the
[The 3AM Fridge Text](https://make.fun/c/u-deysumbrella-the-3am-fridge-text-4c3e721d)
competition on make.fun.

`main.py` (Python 3 stdlib only) writes the entry line to `/output/entry.txt`.
